# DualSubs - 日英字幕＆単語保存

YouTube の視聴ページで、英語字幕（上段）と日本語字幕（下段）を同時表示する Chrome 拡張機能です。
英語字幕の単語をクリックすると単語帳に保存でき、ポップアップから CSV 出力できます。
Language Reactor のような「二言語字幕で学ぶ」という発想を参考に、独自に実装したものです。

## インストール方法（開発者モードで読み込む）

公開（Chrome ウェブストアへの登録）は不要です。手元のフォルダからそのまま読み込めます。

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックする
4. この `dual-subs` フォルダを選択する
5. ツールバーに DualSubs のアイコンが追加されれば完了です

コードを変更したときは、`chrome://extensions` で DualSubs の「更新」ボタンを押すと反映されます。

## 使い方

- YouTube の動画ページを開くと、プレイヤー下部に日英字幕が表示されます
  - 英語字幕が上、日本語字幕が下に表示されます
  - 手動字幕があれば手動字幕を、なければ自動生成字幕を使います
- 英語字幕の単語をクリックすると、その単語が例文・日本語訳・動画へのリンク（再生位置つき）と一緒に保存されます
- プレイヤー右下の「日英」ボタンで、字幕オーバーレイの表示 ON/OFF を切り替えられます
- ツールバーのアイコンを開くと単語帳が表示されます
  - 「CSV出力」：保存した単語を CSV ファイル（UTF-8 BOM 付き）でダウンロードします
  - 「削除」：単語を 1 件ずつ削除、「全削除」：すべて削除します
- YouTube 標準の字幕は別々に動作します。不要な場合はプレイヤーの字幕ボタンから OFF にしてください

## 制限事項

- 二言語表示には、その動画に英語字幕と日本語字幕の両方の字幕トラックが必要です
  - 日本語字幕がない動画では英語のみ表示されます（オーバーレイに注記が出ます）
  - 英語字幕がない動画では字幕を表示できません（注記が出ます）
  - 自動生成字幕でも動作しますが、精度は元の字幕に依存します
- 字幕の機械翻訳は行いません（存在する字幕トラックだけを使います）
- 保存した単語はこのブラウザのローカルストレージ（chrome.storage.local）にのみ保存されます。他の端末とは同期されません
- 対象は PC 版 Chrome の YouTube（www.youtube.com）のみです。スマホの YouTube アプリでは動作しません

## ファイル構成

- `manifest.json` — 拡張機能の定義（Manifest V3）
- `inject.js` — ページ側で字幕トラック情報を取得して渡すスクリプト
- `content.js` — 字幕の取得・同期表示、単語保存の本体
- `content.css` — 字幕オーバーレイのスタイル
- `popup.html` / `popup.js` / `popup.css` — 単語帳ポップアップ
